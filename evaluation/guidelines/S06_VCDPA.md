# Rules for this requirement (they override rubric.md)

VCDPA targeted-advertising opt-out. Element = an actionable control to opt out of targeted advertising, data sale, or profiling (for example a "Personalized ads" or "Targeted advertising" switch). A label or row that only navigates and has no control is NOT the element. Content = it names the practice (ads, sale, profiling, tracking). Behavior = the user can turn it off on that screen or sheet. A pre-selected (enabled) switch is NOT a Behavior failure here: it is a Presentation failure only, and the screen can still comply.
