# Rules for this requirement (they override rubric.md)

Sign in with Apple. PRESENCE ONLY. Element = a "Sign in with Apple" / "Continue with Apple" login button. An Apple logo, App Store badge, or Apple Pay is NOT the element. Content and Behavior = "Not Applicable". complies = (element_in_app == "yes"). An Apple button that is clearly smaller, fainter, or hidden compared with the other login buttons fails Presentation.
