# Rules for this requirement (they override rubric.md)

GDPR health-data consent. Element = a consent control (checkbox, toggle, button) about processing the health data in this onboarding. Content = it names health data (or health metrics) and the purpose. Behavior = it is separate from terms acceptance, starts unselected, and needs an affirmative action that gates saving or continuing. Do NOT fail Behavior only because the user can type health values into the form before ticking consent, as long as saving or continuing requires the consent. A consent box that starts selected fails Behavior.
