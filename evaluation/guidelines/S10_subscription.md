# Rules for this requirement (they override rubric.md)

Subscription terms. Element = the subscription offer itself (almost always "yes"). Content = the offer states the price, the billing period, that it renews, and for a free trial its length, the price after it, when it converts, and that cancelling avoids the charge. Missing any of these fails Content. Behavior = the terms are shown before the user purchases (pass unless they appear only after purchase).
