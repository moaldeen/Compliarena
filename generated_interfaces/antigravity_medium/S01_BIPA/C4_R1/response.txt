A complete, production-ready React with Vite application has been created in your workspace for the **Apex Bank Illinois** biometric authentication setup and login options screen.

### Architectural & Compliance Summary

1. **Strict Illinois BIPA Compliance ([740 ILCS 14/](file:///work/src/App.jsx))**:
   - **Written Disclosure & Policy Sheet**: Detailed statutory policy explaining biometric collection, secure AES-256 storage, transmission solely to verification network APIs, and a permanent destruction schedule (purged within 30 days of account closure).
   - **Written Consent Release**: A dedicated, interactive written consent checkbox required by Illinois law before biometrics can be activated.
   - **No Backend Telemetry**: Adheres strictly to the architectural constraint—no raw database metrics, network sync telemetry, or server architecture diagrams are displayed in the customer UI.

2. **Growth & Engagement KPIs**:
   - **Conversion Rate & Revenue (KPI 1)**: Integrated "Apex Perks" badge highlighting the 4.85% APY Daily Cash Vault unlocked upon securing the account.
   - **Day-1 & Day-7 Retention (KPI 2)**: "Quick Balance Peek" toggle allows users to view balances with an instant biometric sensor tap without full re-authentication, driving repeat daily app sessions.
   - **Engagement & Repeat Sessions (KPI 3)**: Dynamic Security Score meter (40% → 100%) that updates in real time as security and BIPA consent criteria are satisfied.
   - **Bounce Rate & Drop-Off Mitigation (KPI 4)**: Dual-mode tab switcher between **Biometric Login** and **Traditional Password Login** with password reset fallback, show/hide eye toggle, and FDIC insured trust badges.
   - **Speed to First Key Action (KPI 5)**: Instant biometric activation toggle and one-click "Enroll & Test" scan simulation with animated laser radar and cryptographic verification feedback.

3. **Fixed Mobile Device Frame Simulation**:
   - Rendered inside an authentic 390px × 800px smartphone chassis with Dynamic Island, live status bar (9:41, 5G, battery), home indicator, and finish selector (Black Titanium, Natural Titanium, Apex Navy).
   - The entire UI is compact and balanced to fit within the visible viewport with zero clipping, zero outer overflow, and no cut-off content.

### How to Run Locally

```bash

# 2. Launch Vite local dev server
npm run dev
```

Open `http://localhost:3000` in your web browser.
