# Apex Bank Illinois - Mobile Biometric & Password Authentication Setup

A mobile banking security setup screen for iOS/Android simulated in React with Vite, adhering strictly to the **Illinois Biometric Information Privacy Act (BIPA, 740 ILCS 14/)** and optimized for Growth & Engagement KPIs.

---

## Features & Compliance Highlights

1. **Illinois Biometric Information Privacy Act (BIPA) Compliance (740 ILCS 14/):**
   - **Written Policy & Destruction Schedule**: Publicly accessible retention schedule stating biometric identifiers are permanently destroyed within 30 days of account closure.
   - **Specific Purpose Disclosure**: Explains collection, storage, and transmission exclusively to verification network APIs for fraud prevention and authentication.
   - **Written Release / Consent**: Executable consent checkbox and interactive legal disclosure sheet.
   - **Commercial Prohibition Standard**: Explicit confirmation that biometric data is never sold, leased, or traded.

2. **Growth & Engagement KPI Optimizations:**
   - **Maximize Conversion & Revenue**: Biometric enablement unlocks the 4.85% APY Daily Cash Vault & instant wire transfers.
   - **Maximize Day-1 & Day-7 Retention**: "Quick Balance Peek" lets users check balances with a quick sensor tap without entering credentials, boosting daily app check-ins.
   - **Minimize Drop-off & Bounce**: Dual-login architecture provides seamless switching between Biometric (Face ID / Touch ID) and traditional Master Password login.
   - **Minimize Time to First Action**: Single-tap biometric enrollment with live radar laser scan simulation.
   - **Engagement Gamification**: Interactive Security Score meter (40% → 100%) as security and compliance criteria are satisfied.

3. **Device Simulation:**
   - Rendered in a fixed mobile frame (390px × 800px) with Dynamic Island, live status bar (9:41, 5G, Battery), bezel finish toggles (Black Titanium, Natural Titanium, Apex Navy), and mobile home indicator.
   - Entire UI fits fully inside the visible frame with zero clipping, zero scrollbar overflow, and balanced spacing.

## Local Run Instructions

To run this application locally:

```bash
# 1. Install dependencies
npm install

# 2. Start the local Vite development server
npm run dev
```

Open `http://localhost:3000` (or the port shown in your terminal) in any web browser.
