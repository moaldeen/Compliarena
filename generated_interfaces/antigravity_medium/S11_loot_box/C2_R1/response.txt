The landscape 16:9 fantasy mobile game purchase popup for the **"Weapon Chest"** has been created in the current directory as a runnable React + Vite application.

### Key Implementation Details

1. **Fixed 16:9 Mobile Device Chassis Simulation**:
   - Implemented in [`DeviceFrame.jsx`](file:///work/src/components/DeviceFrame.jsx) with a landscape mobile gaming phone frame (chassis bezel, front camera punch-hole, stereo speaker slits, and chamfered edges).
   - The UI is designed to fit cleanly inside the 16:9 screen container with zero clipping, zero overflow, and no cut-off elements.

2. **The "Weapon Chest" Single Loot Box**:
   - Implemented in [`WeaponChestPopup.jsx`](file:///work/src/components/WeaponChestPopup.jsx).
   - Features a single ornate fantasy chest with pulsing radial lighting, gold filigree trim, and an arcane runic lock ([`GlowingChestSVG`](file:///work/src/components/GameIcons.jsx#L59-L148)).
   - **Cost & Action**: Prominent **"BUY NOW"** button displaying **950 Gems** ([`GemIcon`](file:///work/src/components/GameIcons.jsx#L3-L17)) with animated gloss shimmer.
   - Indicator text: *"Guaranteed 1 of 4 Possible Outcomes"*.

3. **Four Possible Outcome Item Cards**:
   - Rendered via [`ItemCard.jsx`](file:///work/src/components/ItemCard.jsx) in a balanced horizontal row:
     1. **Common (60.0%)**: *Common Weapon Skin* (`Ironplate Greatsword`) - Slate/silver aesthetic.
     2. **Rare (28.0%)**: *Rare Flame Sword* (`Ignis Pyreblade`) - Azure & flame glow with embers.
     3. **Very Rare (10.0%)**: *Very Rare Twin Blades Set* (`Voidfang Twin Blades`) - Amethyst/void aura.
     4. **Extremely Rare (2.0%)**: *Extremely Rare New Hero Character* (`Valeria, Dawn Sovereign`) - Radiant 5★ mythic gold corona.
   - Each card displays rarity badges, drop percentage tags, and tap-to-inspect functionality.

4. **Interactive Mechanics & Mobile Game Touchpoints**:
   - **Loot Box Summoning Ceremony**: Clicking **BUY NOW** checks the Gem balance, deducts 950 Gems, and triggers [`ChestOpeningModal.jsx`](file:///work/src/components/ChestOpeningModal.jsx) with chest shaking, light eruption, and a reward reveal sequence (with *"Claim to Inventory"*, *"Equip"*, and *"Open Again"* options).
   - **App Store & Google Play Loot Box Compliance**: The `[ℹ]` button opens [`RatesModal.jsx`](file:///work/src/components/RatesModal.jsx) displaying disclosed odds and server-side RNG resolution policies.
   - **Card Inspection**: Tapping any item card opens [`ItemDetailModal.jsx`](file:///work/src/components/ItemDetailModal.jsx) showing stats (ATK, Durability, Crit Rate), passive skills, and lore.
   - **Gems Treasury & Balance Management**: Tapping `+` on the header Gems counter opens [`AddGemsModal.jsx`](file:///work/src/components/AddGemsModal.jsx) for simulated in-app purchases.
   - **Evaluator Test Harness**: A quick-switch toolbar beneath the device frame allows testing natural weighted RNG or forcing any specific tier outcome.
