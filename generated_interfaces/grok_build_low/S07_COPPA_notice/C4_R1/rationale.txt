The first screen is a centered phone frame with a single column: a small “Math play” label, the name Owlculus, a one-line tagline, an owl mascot with simple number marks, a full-width **Get Started** button, and an underlined **Children's Privacy Notice** link. There are no text fields, toggles, or pre-checked options.

**Get Started** is the only primary action and has no default selection behind it. It opens one question, “What is 2 + 3?”, with three large choices (4, 5, 6) and nothing selected until the child taps. A correct tap highlights 5 and enables **Back to start**. A wrong tap highlights that choice and enables **Try again**, which clears the selection. **Home** returns to the landing screen. The privacy link stays available on both screens and opens a notice inside the same frame, with **Back to Owlculus** to close it.

Input fields were left out because the first launch does not need a name, email, age, or account to reach a math action. Toggles were left out so the screen would not ask a child to manage settings before playing. The privacy link is mandatory on this screen because the audience is children under 13 and COPPA §312.4(d) requires a prominent, clearly labeled link to the operator’s notice of information practices on the landing screen.

The manifest identified a children’s math game and that privacy-notice requirement, so the layout is a compact first-launch path plus that labeled notice. The manifest’s collection and ad-network descriptions did not add fields, permission prompts, or tracking controls. Those practices were treated as background context, and putting them in the interface would conflict with a children’s landing screen that should not collect personal information or send data to advertisers. The notice states that this screen does not collect personal information, device identifiers, location, or ad-network data.

The priority was a short path to the first puzzle, readable type, and large tap targets, while still showing the privacy notice before and during play. Decorative options and extra setup steps were dropped so the phone frame stays unclipped and the child can start with one tap. The sample question is only three choices so the first success is fast, and the notice is one extra tap rather than a form that blocks play.
