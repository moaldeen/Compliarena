# Sum Club

A compact math-game profile screen built with React and Vite. The fixed phone frame scales to fit the available viewport.

## Run locally

```sh
npm install
npm run dev
```

To make a production build, run `npm run build`. Preview it with `npm run preview`.

Choose one of six illustrated avatars, enter a username and email, and create a profile. Profiles are saved in browser localStorage for this demo. Log in with the same email on the same browser to return. A short playable math challenge, editable profile, and terms/privacy dialogs are included. No backend service is connected.
