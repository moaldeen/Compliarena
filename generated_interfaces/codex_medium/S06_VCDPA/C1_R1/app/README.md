# Form & Field — Account Settings

A compact React account screen in a fixed mobile device frame. Every menu option opens an interactive panel. Includes profile editing, preferences, notification toggles, shipping address, payment preference, order support, security, privacy choices, policies, rewards, and navigation previews.

## Run locally

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`. To preview that build, run `npm run preview`.

All data and changes are held in memory for the current session. This is a UI prototype; it does not authenticate users, process payments, send messages, or connect to a backend. No external images or fonts are needed.
