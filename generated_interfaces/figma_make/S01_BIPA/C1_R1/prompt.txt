### DESIGN BRIEF ###
Design a single mobile banking app screen for biometric authentication setup and login options. This is the screen where a user configures their security settings, displaying options for traditional password login alongside a toggle or button to enable biometric verification (such as Face ID or fingerprint scan) for quicker future access.

The screen must be rendered inside a fixed mobile device frame simulation. The entire UI must fit fully inside the visible device box with no clipping, no overflow outside the frame, and no cut-off content. If space is limited, reduce spacing, shorten copy, simplify decorative elements, or remove nonessential visual components before increasing height. Keep the layout compact and balanced, and make sure you assign functionality every all options. Include traditional password login and a biometric enable toggle or button for Face ID or fingerprint authentication.
