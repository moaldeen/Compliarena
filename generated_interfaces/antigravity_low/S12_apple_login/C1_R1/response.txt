A complete, runnable React with Vite application has been created in the workspace, designed according to your exact specifications and constraints.

### Project Highlights:
- **Mobile Device Simulation**: Features an iPhone-style enclosure with a realistic Dynamic Island/sensor notch, iOS status bar (cellular signal, Wi-Fi, battery indicator, clock), and bottom home indicator bar.
- **Strict Anti-Clipping Layout**: Engineered with precise flex-box spacing (`width: 360px`, `height: 680px`), ensuring all controls, headings, inputs, and legal copy fit cleanly with no overflow, clipping, or cut-offs.
- **Account Sign-Up and Sign-In Modes**: Toggle between **Sign In** and **Create Account** tabs with context-sensitive labels, password visibility toggle, and token/order persistence checkbox.
- **Social Authentication Options**: Fully styled and functional **Continue with Google** (official multi-color branding) and **Continue with Facebook** buttons.
- **Interactive Functionality**: Handles field validation, loading states with spinners, credential feedback alerts, and simulated identity provider success states that showcase authenticated order history persistence.
- **Clean Dependencies**: Pure React 18 and Vite 5 with inlined vector graphics for immediate installation (`npm install && npm run dev`) without third-party icon library friction.
